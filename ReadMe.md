# 10月進捗
## シーン遷移
スペースキーでゲームシーンとタイトルシーンを切り換え

## 単色フェード
シーン遷移時に黒の単色フェードを実装

## 自キャラ操作
ADで自キャラを左右に操作可能、 Wでジャンプも可

## 地形物との当たり判定  
マップチップで描画した地形とのめりこみ排斥

## デス演出
F2キーでデス演出→タイトルへ遷移

# 11月進捗
## まっすぐ飛ぶ弾
SPACEキーで弾を発射。z軸の方向に進んでいく。

## 弾数制限・リロード
弾を10発撃つと3秒間のリロードタイムが入る。

## 基本の雑魚敵
奥と手前を行き来する敵を作成。F4でランダムな位置にポップする。

## 敵のデス演出
自弾を敵に当てると死亡演出が入りその後消滅する。
