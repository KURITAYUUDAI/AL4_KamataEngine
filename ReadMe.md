# 11月進捗
## 操作方法
矢印キーでXY平面の移動、WSでZ軸の移動、ADでY軸の回転を調整  
スペースで弾を発射、長押しで連射可能。  
F2で死亡演出。F3でシーン遷移。F4で敵の追加。
## 今月の成果一覧
- まっすぐ飛ぶ弾
  - SPACEキーで弾を発射。z軸の方向に進んでいく。
- 弾数制限・リロード
  - 弾を10発撃つと3秒間のリロードタイムが入る。
- 基本の雑魚敵
  - 奥と手前を行き来する敵を作成。F4でランダムな位置にポップする。
- 敵のデス演出
  - 自弾を敵に当てると死亡演出が入りその後消滅する。

# 10月進捗
## 操作方法
ADで移動、Wでジャンプ  
スペースでシーン遷移。F2で死亡演出。
## 今月の成果一覧
- シーン遷移
  - スペースキーでゲームシーンとタイトルシーンを切り換え
- 単色フェード
  - シーン遷移時に黒の単色フェードを実装
- 自キャラ操作
  - ADで自キャラを左右に操作可能、 Wでジャンプも可
- 地形物との当たり判定  
  - マップチップで描画した地形とのめりこみ排斥
- デス演出
  - F2キーでデス演出→タイトルへ遷移
